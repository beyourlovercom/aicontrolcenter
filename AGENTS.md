# AI Control Center Agent Contract

## Authority

`origin/main` exact SHA and formal governance documents are authoritative.

OpenSpec, Oh My OpenCode Slim, OpenCode sessions, runtime state, dashboards, and agent output are non-authoritative.

## Permanent denials

- Arbitrary shell strings from the UI.
- OpenSpec sync.
- Automatic authorization.
- Automatic next Work Package.
- Parallel writers.
- Automatic push, PR creation, merge, migration, or deployment.

## Current implementation phase

The `v0.2.0-visible` application is presentation-only and read-only. Do not introduce process execution or repository writes into this Work Package.
